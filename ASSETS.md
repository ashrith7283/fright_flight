# Assets

Record of the origin and licence of every art and audio asset. All assets are original
or CC0; none are copied from other games.

All files are CC0 (public domain dedication) by Juhani Junkala. Per-file sources are in
[`assets/audio/CREDITS.md`](assets/audio/CREDITS.md).

| `flap.wav` | CC0 |
| `score.wav` | CC0 |
| `crash.wav` | CC0 |
| `music.m4a` | CC0 |

## Launcher icon (`assets/icon/`)
| File | Source | Licence |
|------|--------|---------|
| `background.png`, `foreground.png`, `icon.png` | Generated by [`tool/make_icon.py`](tool/make_icon.py) (original artwork, drawn with Pillow) | Original, owned by the developer |

Regenerate with `python3 tool/make_icon.py`, then `dart run flutter_launcher_icons`.

## In-game art
The plane, clouds, birds, smoke, sun and background are drawn in code (Flame canvas);
there are no external image files.

## Fonts and icons
UI icons come from Flutter's bundled Material Icons (Apache 2.0).
